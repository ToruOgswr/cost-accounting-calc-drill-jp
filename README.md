# 原価計算 計算論点ドリル

原価計算WEEK1〜8の主要な計算論点を、3問・3分で確認する教育用Webアプリです。問題と採点はブラウザ内で処理し、回答や利用者情報を保存・送信しません。

## 機能

- WEEK1〜8の計算問題
- 正誤問題と四択問題
- 3分の制限時間
- 回答直後の解説と3問終了後の結果表示

## 開発

Node.js 22.13以降とpnpmを使用します。

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm run build
```

問題の正本は `SOURCE/`、生成済みデータは `data/questions.json` です。生成済みデータを直接編集せず、`pnpm run build:questions`を使用してください。

## データの取扱い

回答は端末内のメモリだけで処理します。データベース、Cookie、ブラウザの永続保存領域、外部APIは使用しません。個人情報、成績、学籍番号は収集しません。
