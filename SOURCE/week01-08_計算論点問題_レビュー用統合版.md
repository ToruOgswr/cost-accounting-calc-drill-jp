### 四択問題（個別原価計算の基礎）

#### 四択 Q1-1

製品#101の直接材料費は25,000円、直接労務費は55,000円である。#101の直接費合計はいくらか。

1. 30,000円
2. 55,000円
3. 80,000円
4. 95,000円

**正答：3（80,000円）**

**解説：** 直接費合計は、直接材料費25,000円と直接労務費55,000円の合計である。

#### 四択 Q1-2

間接材料費15,000円、間接労務費40,000円、水道光熱費7,500円、減価償却費17,500円が発生した。製造間接費の合計はいくらか。

1. 55,000円
2. 65,000円
3. 72,500円
4. 80,000円

**正答：4（80,000円）**

**解説：** 15,000円＋40,000円＋7,500円＋17,500円＝80,000円である。

#### 四択 Q1-3

製造間接費80,000円を直接作業時間で実際配賦する。#101が55時間、#102が45時間の場合、#101への配賦額はいくらか。

1. 36,000円
2. 40,000円
3. 44,000円
4. 55,000円

**正答：3（44,000円）**

**解説：** 合計100時間のうち#101は55時間であるため、80,000円×55時間÷100時間＝44,000円となる。

### 正誤問題（個別原価計算の基礎）

#### 正誤 Q1-2

工場全体で共通して発生する水道光熱費は、通常、特定の製品の直接経費として処理する。

- 適切である
- 不適切である

**正答：不適切である**

**解説：** 工場全体で共通して発生する水道光熱費は、通常は間接経費として製造間接費に集計する。

#### 正誤 Q1-3

製造間接費を直接作業時間で配賦する場合、各製品への配賦額は「製造間接費の総額÷直接作業時間の合計×各製品の直接作業時間」で計算する。

- 適切である
- 不適切である

**正答：適切である**

**解説：** 総額を配賦基準の合計で割って配賦率を求め、それに各製品の配賦基準数値を掛ける。

#### 正誤 Q1-4

当月末に未完成の製品に集計された原価は、当月の売上原価として処理する。

- 適切である
- 不適切である

**正答：不適切である**

**解説：** 未完成品に集計された原価は月末仕掛品として翌月へ繰り越し、販売されるまでは売上原価にしない。

#### 正誤 Q1-5

個別原価計算では、製造指図書ごとに直接材料費、直接労務費および配賦された製造間接費を集計する。

- 適切である
- 不適切である

**正答：適切である**

**解説：** 個別原価計算では、製造指図書ごとに直接費と配賦された製造間接費を集計して製品原価を求める。

#### 四択 Q2-1

主要材料の月初有高は5kg・10,400円、当月購入は21kg・54,600円である。平均法による1kg当たりの単価はいくらか。

1. 2,080円
2. 2,400円
3. 2,500円
4. 2,600円

**正答：3（2,500円）**

**解説：** （10,400円＋54,600円）÷（5kg＋21kg）＝2,500円/kgである。


#### 四択 Q2-3

前月未払賃金49,000円、当月支払賃金154,000円、当月未払賃金35,000円である。当月の賃金消費額はいくらか。

1. 105,000円
2. 140,000円
3. 154,000円
4. 238,000円

**正答：2（140,000円）**

**解説：** 当月支払額154,000円＋当月未払額35,000円−前月未払額49,000円＝140,000円である。

### 正誤問題（材料費・労務費の計算）

#### 正誤 Q2-1

平均法による材料の消費単価は、月初材料と当月購入材料の合計金額を、それらの合計数量で割って計算する。

- 適切である
- 不適切である

**正答：適切である**

**解説：** 平均法では、利用可能な材料の合計金額を合計数量で割って平均単価を求める。

#### 正誤 Q2-2

先入先出法では、後から購入した材料から先に消費されたものとして消費原価を計算する。

- 適切である
- 不適切である

**正答：不適切である**

**解説：** 先入先出法は、先に購入した材料から先に消費されたものとして消費原価を計算する。

#### 正誤 Q2-3

棚卸計算法による材料消費額は、一般に「月初有高＋当月購入額−月末有高」で計算する。

- 適切である
- 不適切である

**正答：適切である**

**解説：** 棚卸計算法では、利用可能額から月末有高を差し引くことで当月消費額を求める。

#### 正誤 Q2-4

賃金の当月消費額は、「当月支払額＋当月未払額−前月未払額」で計算する。

- 適切である
- 不適切である

**正答：適切である**

**解説：** 当月支払額から前月分の未払額を除き、当月末の未払額を加えると当月消費額になる。

#### 四択 Q3-1

製造間接費の予定配賦率は780円/時間である。製品#101の直接作業時間が55時間の場合、予定配賦額はいくらか。

1. 35,100円
2. 42,900円
3. 55,000円
4. 78,000円

**正答：2（42,900円）**

**解説：** 780円/時間×55時間＝42,900円である。

#### 四択 Q3-2

製造間接費の予定配賦率は780円/時間である。製品#102の直接作業時間が45時間の場合、予定配賦額はいくらか。

1. 32,000円
2. 35,100円
3. 42,900円
4. 45,000円

**正答：2（35,100円）**

**解説：** 780円/時間×45時間＝35,100円である。

#### 四択 Q3-3

製造間接費の実際発生額が80,000円、予定配賦額が78,000円であった。原価差異はいくらか。

1. 2,000円の不利差異
2. 2,000円の有利差異
3. 78,000円の不利差異
4. 差異はない

**正答：1（2,000円の不利差異）**

**解説：** 実際発生額が予定配賦額を2,000円上回るため、2,000円の不利差異である。

### 正誤問題（製造間接費の予定配賦）

#### 正誤 Q3-2

直接作業時間を配賦基準とする場合、製品への予定配賦額は「予定配賦率×その製品の実際直接作業時間」で計算する。

- 適切である
- 不適切である

**正答：適切である**

**解説：** 予定配賦率に各製品が実際に消費した配賦基準数値を掛けると、その製品への予定配賦額になる。

#### 正誤 Q3-4

予定配賦を採用すると、製造間接費の実際発生額が確定する前でも、製品原価を計算しやすくなる。

- 適切である
- 不適切である

**正答：適切である**

**解説：** 予定配賦では実際額の確定を待たずに配賦できるため、製品原価を迅速に計算できる。

#### 正誤 Q6-1

月初仕掛品がある場合の数量関係は、「月初仕掛品数量＋当月投入数量＝当月完成数量＋月末仕掛品数量」となる。

- 適切である
- 不適切である

**正答：適切である**

**解説：** 投入側の月初仕掛品と当月投入の合計は、産出側の完成品と月末仕掛品の合計に一致する。

#### 正誤 Q6-2

平均法では、月初仕掛品原価と当月製造費用を合算して、完成品と月末仕掛品に配分する。

- 適切である
- 不適切である

**解説：** 平均法は月初仕掛品原価と当月製造費用を一体として平均し、完成品と月末仕掛品へ配分する。

- 不適切である

#### 四択 Q8-1

製品1個当たりの標準直接材料は、標準単価500円/kg、標準消費量3kgである。標準直接材料費はいくらか。

2. 1,000円

**正答：3（1,500円）**

**解説：** 500円/kg×3kg＝1,500円である。

材料の標準単価は500円/kg、実際単価は520円/kg、実際消費量は100kgである。材料価格差異はいくらか。

1. 2,000円の不利差異
2. 2,000円の有利差異
3. 50,000円の不利差異
4. 差異はない

**解説：** （実際単価520円−標準単価500円）×実際消費量100kg＝2,000円の不利差異である。

#### 四択 Q8-3

材料の標準単価は500円/kg、実際消費量は100kg、実際生産量に対する標準消費量は90kgである。材料数量差異はいくらか。

### 正誤問題（標準原価計算と差異分析）

#### 正誤 Q8-1

製品1個当たりの標準直接材料費は、「標準単価×標準消費量」で計算する。

- 適切である
- 不適切である

**正答：適切である**

**解説：** 標準原価カードでは、標準単価と製品1個当たりの標準消費量を掛けて標準直接材料費を求める。

実際材料単価が標準材料単価を下回った場合、その他の条件が同じであれば材料価格差異は不利差異となる。

- 適切である
- 不適切である

**正答：不適切である**

**解説：** 実際単価が標準単価を下回れば実際原価が標準より低くなるため、材料価格差異は有利差異となる。
